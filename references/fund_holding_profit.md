# 基金持仓收益

## 调用

每只基金需要代码或名称、每份成本价和持有份额。

用户未附持仓时，按 [基金持仓记录](fund_holding_record.md) 的记忆读取规则获取当前持仓。记录缺失、不完整或冲突时询问用户，不得猜测。

```bash
python3 scripts/fund_holding_profit.py \
  --holding "270023,4.5071,11778.31" \
  --holding "000002,1.0000,2000" \
  --json
```

单只基金使用一个 `--holding`。只有脚本成功后才能给出收益数值。

## 数据

- `fund_value_estimation_em()`：盘中估值。
- `fund_open_fund_daily_em()`：批量公布净值。
- `fund_open_fund_info_em()`：批量数据缺失时补充历史净值。

基金支持代码、完整名称或唯一名称片段。名称有多个匹配时要求使用代码。

## 价格选择

- 交易日 09:30–15:00：优先使用当天估值。
- 交易日 15:00 后：优先使用当天净值；未公布时使用当天估值并标记待确认。
- 其他时段或估值不可用：使用最新公布净值。

使用 Asia/Shanghai 时区。估值不能冒充正式净值；数据日期不是今天时，不得表述为今日实时涨幅。当前净值、前净值或日增长率缺失时，用历史净值补齐并计算。

## 收益口径

```text
持有成本 = 持仓成本价 × 持有份额
当前市值 = 最新单位净值 × 持有份额
持仓收益 = 当前市值 - 持有成本
收益率 = 持仓收益 ÷ 持有成本 × 100%
当日收益 = (最新单位净值 - 前一交易日单位净值) × 持有份额
```

成本价指每份成本，份额指当前持有份额。结果不考虑费用、分红、当日交易和净值确认时差。

## 输出

- 表头：基金、日期、日涨幅、持有成本、持仓收益、收益率、当日收益。
- 表格后追加：`合计持有成本 **¥…**，持仓收益 **¥…**，当日收益 **¥…**`。
- 任一基金缺少当日收益时，合计当日收益显示“暂无”。
- 使用估值时，提醒最终结果以基金公司净值为准。
- 不展示价格状态、当前净值、前净值、成本价、份额和当前市值。

接口字段、估值覆盖范围和更新时间以 [AkShare 公募基金官方文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)为准。
