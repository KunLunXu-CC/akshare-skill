# 开放式基金持仓收益

## 使用范围

本能力使用 AkShare 的 `fund_value_estimation_em()` 获取盘中估值，使用 `fund_open_fund_daily_em()` 获取批量公布净值，并在批量字段为空时使用 `fund_open_fund_info_em()` 获取单只基金历史净值。基金可以使用代码、完整名称或唯一的名称片段指定。

该接口通常在交易日 16:00–23:00 更新当日净值。查询结果必须展示数据日期；如果数据日期不是今天，应说明这是最新已公布数据，不能将其表述为今日实时涨幅。

## 价格选择

脚本以 Asia/Shanghai 时区判断市场阶段：

| 市场阶段 | 价格选择 | 表格状态 |
| --- | --- | --- |
| 交易日 09:30–15:00 | 优先使用当天估值 | 盘中估值 |
| 交易日 15:00 后且当天净值已发布 | 使用当天公布净值 | 盘后净值 |
| 交易日 15:00 后但净值未发布 | 使用当天估值 | 盘后估值（净值待公布） |
| 盘前 | 使用最新公布净值 | 盘前最新净值 |
| 周末或非交易时段 | 使用最新公布净值 | 非交易日最新净值 |

估值接口可能没有覆盖指定基金或暂时返回空数据。此时不得报出虚假的盘中收益，应回退到最新已公布净值并标注“暂无盘中估值”。QDII 等基金的正式净值可能延迟公布，盘后估值不能冒充正式净值。

批量公布净值中的当前净值、前一净值或日增长率为空时，不应直接判定查询失败。应读取单只基金历史净值补齐：单位净值取最近一个有效记录，前一净值取倒数第二个有效记录，日增长率缺失时使用相邻两个有效净值计算。这些净值用于内部计算，最终表格按下文的精简格式展示。

## 调用方法

查询脚本可以直接由系统 `python3` 启动。如果 AkShare 已安装在技能目录的 `.venv` 中，脚本会自动切换到该解释器，不要求调用方提前激活虚拟环境，也不应重复安装依赖。

```bash
# 按基金代码查询持仓收益
python3 scripts/fund_holding_profit.py 270023 --cost-price 4.5071 --shares 11778.31

# 供程序或 Agent 读取
python3 scripts/fund_holding_profit.py 270023 --cost-price 4.5071 --shares 11778.31 --json

# 批量查询；每只基金重复提供一次“基金,成本价,份额”
python3 scripts/fund_holding_profit.py \
  --holding "270023,4.5071,11778.31" \
  --holding "000002,1.0000,2000" \
  --json
```

批量参数支持英文逗号或中文逗号，但数字中不要使用千位分隔符。返回顺序与输入顺序一致；单只基金的 JSON 是对象，多只基金的 JSON 是对象数组。

如果名称匹配多个基金，必须列出候选项并要求改用基金代码，不能自行选择。

## 输出格式

Markdown 表格使用“基金、日期、日涨幅、持有成本、持仓收益、收益率、当日收益”作为表头。价格状态、当前净值、前净值、持仓成本价、份额和当前市值仍保留在 JSON 中供计算和判断，但不作为最终表格列展示。

表格后追加粗体金额摘要：`合计持有成本 **¥…**，持仓收益 **¥…**，当日收益 **¥…**`。合计值按所有基金求和；只要有一只基金缺少当日收益，合计当日收益就显示“暂无”，不得只汇总部分基金。

## 收益口径

`--cost-price` 表示每份基金的持仓成本价，`--shares` 表示当前持有份额。两者都必须由用户提供，不得推测。

```text
持有成本 = 持仓成本价 × 持有份额
当前市值 = 最新单位净值 × 持有份额
持仓收益 = 当前市值 - 持有成本
收益率 = 持仓收益 ÷ 持有成本 × 100%
当日收益 = (最新单位净值 - 前一交易日单位净值) × 持有份额
```

计算结果不考虑申购费、赎回费、现金分红、红利再投资、当日交易和净值确认时差。缺少成本价或份额时，应向用户询问缺失值，不能直接调用脚本。

## 触发示例

以下请求应触发本技能：

- `查询持仓收益 基金 270023 持仓成本 4.5071 持有份额 11778.31`
- `帮我算 270023 的持仓盈亏，成本价 4.5071，份额 11778.31`
- `广发全球精选股票持有收益多少？成本 4.5071，持有 11778.31 份`
- `查询以下基金持仓收益：270023 成本 4.5071 份额 11778.31；000002 成本 1.0000 份额 2000`

## 数据边界

- 当前仅支持 `fund_open_fund_daily_em()` 覆盖的开放式基金。
- 净值数据不是盘中实时价格。
- 非交易日或净值尚未公布时返回最近一个已公布交易日的数据。
- 名称匹配存在歧义时不得计算收益。
- 当前不查询基金披露的股票或债券组合；“持仓”指用户持有的基金份额。

接口字段、估值覆盖范围和更新时间以 [AkShare 公募基金官方文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)为准。
