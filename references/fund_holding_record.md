# 基金持仓记录

## 使用范围

用户说“提取持仓信息”，或要求从支付宝等截图添加、记录、保存、更新基金持仓时使用。调用本能力即表示需要在记忆可用时保存结果。

## 提取与计算

从截图提取基金代码或名称、持有金额、持有收益和持有收益率。昨日收益不参与持仓计算。

调用脚本获取最新公布净值并计算：

```text
持有成本 = 持有金额 - 持有收益
份额 = 持有金额 ÷ 最新公布净值
成本价 = 持有成本 ÷ 份额
```

```bash
python3 scripts/fund_holding_record.py \
  --record "广发全球精选股票(QDII)A,74566.12,21480.05,40.46%" \
  --json
```

每只基金重复使用一个 `--record`。名称被截图截断时保留可见前缀，脚本只接受唯一匹配。脚本会用截图收益率交叉校验；结果为“待确认”时不得写入记忆，也不影响其他基金继续计算。

## 更新记忆

平台支持持久化记忆时：

1. 先搜索现有“当前基金持仓”。OpenClaw 使用 `memory_search`，再用 `memory_get` 核对原文。
2. 只写入脚本标记为“可记录”的结果，记录字段保持为基金代码、基金名称、成本价、份额和更新时间。
3. 按基金代码更新；空字段不得覆盖记忆中的已有值。
4. 仅新增或更新本次提供的基金；除非用户明确要求，不删除其他持仓。

记忆使用以下格式：

```markdown
## 当前基金持仓

| 基金代码 | 基金名称 | 成本价 | 份额 | 更新时间 |
| --- | --- | ---: | ---: | --- |
| `<代码>` | `<名称>` | `<每份成本价>` | `<持有份额>` | `<YYYY-MM-DD>` |
```

平台没有持久化记忆时仍输出计算结果，并说明本次未保存。

## 输出

使用中文 Markdown 表格：

| 基金 | 成本价 | 份额 | 处理结果 |
| --- | ---: | ---: | --- |

写入记忆后将“可记录”改为“已添加”或“已更新”。表格后说明是否已写入记忆。
